# Training App 2 — мій менеджер витрат

Я розробляю цей навчальний консольний проєкт на C# та .NET 10, щоб практикувати програмування на конкретних задачах. Поступово додаю нові можливості й розбираюся з методами, класами, колекціями, перевіркою введення, LINQ та збереженням даних у JSON.

## Що я вже реалізував

- Додавання витрати з назвою, додатною сумою та категорією.
- Перевірку порожнього введення та некоректної суми.
- Скасування введення командою `exit` під час додавання, пошуку за категорією та видалення.
- Перегляд усіх витрат і підрахунок загальної суми.
- Пошук за категорією без урахування великих і малих літер.
- Універсальний метод фільтрації списку через LINQ.
- Видалення витрати: пошук за частиною назви, категорією, точною сумою або ID, вибір знайденого запису за ID та підтвердження видалення.
- Збереження витрат у JSON після додавання або видалення та завантаження під час запуску.
- Визначення наступного ID за найбільшим ID серед завантажених записів.

У розділі статистики я вже показую:

- кількість витрат;
- загальну суму;
- середню витрату;
- мінімальну та максимальну суми;
- загальну суму за кожною категорією.

Для підсумків за категоріями я використовую `Dictionary<string, decimal>`. Назви категорій порівнюю без урахування регістру.

## Як запустити

Для запуску потрібен .NET 10 SDK. У папці проєкту виконую:

```sh
dotnet build "Trainig app 2.slnx"
dotnet run --project "Trainig app 2.csproj"
```

Після запуску обираю дію за номером у головному меню. Статистика відкривається пунктом `7`, вихід із програми — пунктом `0`. Під час запитів даних команда `exit` скасовує поточну операцію. Після операцій програма може попросити натиснути Enter перед поверненням до меню.

Суми програма читає через `decimal.TryParse` із поточними регіональними налаштуваннями системи, тому десятковий роздільник залежить від цих налаштувань.

## Де зберігаються дані

Я зберігаю записи у файлі `expenses.json` у поточній робочій папці програми. Файл створюється після першого успішного додавання витрати. До репозиторію він не потрапляє, тому кожен користувач починає зі своїх даних.

Також я виключив із Git папки збірки та локальні файли редактора через `.gitignore`.

## Що планую доробити

Я продовжую розвивати проєкт. У меню глобального пошуку вже працює пошук за категорією; пошук за назвою та сумою поки реалізований у сценарії видалення, але ще не підключений до окремих пунктів цього меню.

Далі планую:

- підключити пошук за назвою та сумою в меню;
- винести показ одного запису та пошук за ID в окремі методи;
- розділити обчислення й виведення суми, щоб у статистиці вона не показувалася двічі;
- узгодити повідомлення для порожнього списку;
- поступово рознести код по окремих файлах;
- перевірити граничні сценарії введення, пошуку та статистики.

Детальний список виконаних і запланованих задач веду в [ToDo.md](ToDo.md).
