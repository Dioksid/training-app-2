# Training App 2 — менеджер витрат

Навчальний консольний проєкт на C# та .NET 10. Проєкт розвивається поступово для практики роботи з методами, колекціями, перевіркою введення, LINQ та JSON.

## Реалізовано

- Додавання витрат: назва, додатна сума та категорія.
- Перевірка порожнього та некоректного введення; команда `exit` для скасування додавання або видалення.
- Перегляд усіх витрат і підрахунок загальної суми.
- Пошук за категорією без урахування регістру.
- Універсальний метод фільтрації через LINQ.
- Видалення витрат: пошук за частиною назви, категорією, точною сумою або ID, вибір запису й підтвердження.
- Збереження в JSON та завантаження витрат під час запуску.
- Відновлення наступного ID за найбільшим наявним ID.

## Запуск

Потрібен .NET 10 SDK.

```sh
dotnet build "Trainig app 2.slnx"
dotnet run --project "Trainig app 2.csproj"
```

Дані зберігаються в `expenses.json` у поточній робочій папці програми. Цей файл не включається до репозиторію. Після першого додавання витрати програма створить його сама.

## Поточний стан

Це навчальний проєкт у процесі розробки. Пошук за назвою та сумою вже використовується в сценарії видалення, але ще не підключений до окремих пунктів меню глобального пошуку. Статистика поки не реалізована. `Finde.cs` містить заготовку окремого класу.

Наступні задачі та їхній стан записані в [ToDo.md](ToDo.md). Зокрема, заплановано винести показ витрати й пошук за ID в окремі методи.

## Файли

- `Program.cs` — модель витрати, меню, введення, пошук, видалення та збереження.
- `Finde.cs` — заготовка класу для подальшого розділення коду.
- `Trainig app 2.csproj` — налаштування проєкту.
- `Trainig app 2.slnx` — файл рішення.
- `ToDo.md` — план розвитку.
